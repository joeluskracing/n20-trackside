# Trackside v2

The new web-based racecar notebook is in [v2/](v2/README.md). The original Electron app remains at the repository root.

The new version includes session history, an isometric chassis setup view, voice/text/photo capture, configurable fields, session locks, an audit trail, CSV import/export, and printable PDF reports. Live AI features require connecting an OpenAI API key.

See the [v2 README](v2/README.md) for setup, data format, validation results, and current limitations.
